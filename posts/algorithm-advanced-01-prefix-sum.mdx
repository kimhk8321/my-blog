처음에는 숫자 세 개만 보겠습니다. 배열이 `[1, -1, 1]`이고 **연속해서 고른 숫자의 합이 1인 구간**이 몇 개인지 묻는 문제입니다. 원소의 순서는 그대로 두고, 아무것도 고르지 않은 구간은 세지 않습니다.

## 손으로 먼저 답을 구하기

| 고른 위치 | 숫자 | 합 |
| --- | --- | --- |
| 0번만 | `[1]` | 1 |
| 2번만 | `[1]` | 1 |
| 0~2번 | `[1,-1,1]` | 1 |

정답은 **3개**입니다. 0번의 1과 2번의 1은 값은 같아도 위치가 달라 서로 다른 구간입니다.

가장 단순하게는 시작점을 하나 정하고, 끝점을 오른쪽으로 옮기며 합을 구합니다. 앞에서 배운 반복문만으로 작성할 수 있습니다.

```js
function countTargetSlow(nums, target) {
  let answer = 0;
  for (let start = 0; start < nums.length; start++) {
    let sum = 0;
    for (let end = start; end < nums.length; end++) {
      sum += nums[end];
      if (sum === target) answer++;
    }
  }
  return answer;
}
```

이 함수도 정답은 맞습니다. 다만 시작점이 바뀔 때마다 비슷한 합을 다시 구해서 시간은 O(n²)입니다. 이 반복을 줄이는 것이 이번 편의 목표입니다.

## 누적합은 앞에서부터 더한 값

`prefix`는 지금까지 읽은 값을 전부 더한 합입니다. 예제에서는 이렇게 바뀝니다.

```text
아무것도 읽기 전: 0
0번까지 읽음:     1
1번까지 읽음:     0
2번까지 읽음:     1
```

마지막까지 더한 합은 1입니다. 여기서 앞의 두 숫자 합 0을 빼면 마지막 숫자만의 합도 1입니다. **현재까지의 합에서 앞부분의 합을 빼면, 남은 뒷부분의 합**이 됩니다.

```text
현재까지의 합 - 앞부분의 합 = 원하는 합
앞부분의 합 = 현재까지의 합 - 원하는 합
```

그래서 현재 prefix가 1이고 target이 1이면, 앞에서 누적합이 0이었던 위치를 찾습니다.

## Map에는 합과 등장 횟수를 저장한다

`counts`는 [기초 편의 개수 세기 Map](/posts/algorithm-01-hash)과 같은 형태입니다. key는 누적합, value는 그 누적합이 나온 횟수입니다.

```text
{0: 2, 1: 1}
→ 앞부분의 합이 0인 위치가 두 번, 1인 위치가 한 번 있었다.
```

처음의 `new Map([[0, 1]])`은 **배열 시작 전의 합 0을 한 번 기록**한 것입니다. 그래야 맨 앞에서 시작하는 구간도 셀 수 있습니다.

## 세 번의 반복을 따라가기

아래 counts는 각 원소를 처리하고 현재 prefix까지 등록한 상태입니다. 답을 구할 때는 등록 전의 counts를 조회합니다.

| 읽은 값 | prefix | 찾는 합 `prefix - 1` | 새 구간 | 누적 답 | 등록 후 counts |
| --- | --- | --- | --- | --- | --- |
| 시작 전 | 0 | — | — | 0 | `{0:1}` |
| 0번의 1 | 1 | 0 | 1개 | 1 | `{0:1, 1:1}` |
| 1번의 -1 | 0 | -1 | 0개 | 1 | `{0:2, 1:1}` |
| 2번의 1 | 1 | 0 | 2개 | 3 | `{0:2, 1:2}` |

마지막 반복에서는 앞부분의 합 0이 두 번 있었습니다. **시작 전의 0**을 빼면 `[1,-1,1]`, **1번까지 더한 0**을 빼면 마지막 `[1]`입니다. 같은 누적합을 한 개로 덮어쓰지 않고 횟수를 저장하는 이유입니다.

## 전체 JS 코드

```js
function countTargetSubarrays(nums, target) {
  const counts = new Map([[0, 1]]);
  let prefix = 0;
  let answer = 0;

  for (const value of nums) {
    prefix += value;
    answer += counts.get(prefix - target) ?? 0;
    counts.set(prefix, (counts.get(prefix) ?? 0) + 1);
  }
  return answer;
}

console.log(countTargetSubarrays([1, -1, 1], 1));
console.log(countTargetSubarrays([0, 0], 0));
```

출력은 둘 다 3입니다. `counts.get(...) ?? 0`은 찾는 합이 Map에 없으면 0개로 처리합니다. `counts.set(prefix, ...)`는 현재 합의 횟수를 한 번 늘립니다.

**조회 후 등록** 순서도 중요합니다. 먼저 등록하면 target이 0일 때 방금 등록한 자기 자신까지 세어서 길이 0인 구간이 들어갑니다.

## 기억할 부분

이 방법은 **정확한 합을 가진 구간의 개수**를 구합니다. 음수가 있어도 합의 차이 식은 유지됩니다. Map 접근을 평균 O(1)로 가정하면 시간 O(n), 공간 O(n)입니다. 예제의 합과 답은 JS 안전 정수 범위 안이라고 가정합니다.
