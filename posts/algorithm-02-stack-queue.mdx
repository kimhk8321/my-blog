스택과 큐는 값을 넣는 방법보다 **꺼내는 순서**가 중요합니다. 가장 최근에 넣은 값을 먼저 꺼내면 스택, 가장 먼저 넣은 값을 먼저 꺼내면 큐입니다. JS에서는 둘 다 배열로 구현할 수 있습니다.

## 스택: push와 pop

```js
const stack = [];
stack.push(1);
stack.push(2);
stack.push(3);

console.log(stack[stack.length - 1]);
console.log(stack.pop());
console.log(stack.pop());
```

맨 위의 값은 3이고, 꺼내는 순서는 3, 2입니다. `pop()`은 마지막 값을 반환하면서 배열에서 제거합니다.

| 문법 | 역할 |
| --- | --- |
| `stack.push(value)` | 맨 위에 추가 |
| `stack.pop()` | 맨 위에서 제거하고 반환 |
| `stack[stack.length - 1]` | 제거하지 않고 맨 위 확인 |
| `stack.length === 0` | 비었는지 확인 |

## 대표 예제: 올바른 괄호

문자열에는 `(`와 `)`만 있습니다. 열린 괄호를 스택에 넣고, 닫힌 괄호가 나오면 하나 꺼냅니다.

```js
function isBalanced(text) {
  const opened = [];

  for (const char of text) {
    if (char === "(") {
      opened.push(char);
    } else {
      if (opened.length === 0) return false;
      opened.pop();
    }
  }
  return opened.length === 0;
}

console.log(isBalanced("(())()"));
console.log(isBalanced("(()"));
console.log(isBalanced(")("));
```

답은 `true`, `false`, `false`입니다. `"(())"`를 따라가면 스택은 이렇게 바뀝니다.

```text
( → [(]
( → [(, (]
) → [(]
) → []
```

닫는 괄호가 나왔는데 스택이 비었으면 짝이 없습니다. 끝까지 읽고 열린 괄호가 남아 있어도 실패입니다. 빈 문자열은 `true`로 처리합니다.

시간 O(n), 추가 공간은 열린 괄호가 쌓이는 만큼 필요하므로 최악 O(n)입니다. 괄호가 한 종류라면 숫자로 개수만 세어도 되지만, 여기서는 스택 사용을 연습하기 위해 배열을 썼습니다.

## 큐: push와 head

큐는 들어온 순서대로 읽습니다. 배열 앞부분을 제거하는 `shift()`로도 만들 수 있지만, 많은 값을 반복 처리할 때는 **읽을 위치를 저장하는 head**를 자주 씁니다.

```js
function processQueue(values) {
  const queue = [...values];
  const result = [];
  let head = 0;

  while (head < queue.length) {
    const value = queue[head];
    head++;
    result.push(value);
  }
  return result;
}

console.log(processQueue(["A", "B", "C"]));
```

결과는 `["A", "B", "C"]`입니다. 위 코드는 순서를 보여 주기 위한 예제입니다. 실제 탐색에서는 꺼낸 값에서 다음에 처리할 항목을 찾아 `queue.push(next)`로 추가합니다.

```text
queue = [A, B, C]
head = 0 → A 처리
head = 1 → B 처리
head = 2 → C 처리
head = 3 → 종료
```

읽은 원소를 배열에서 지우지 않아도 head 이전은 다시 읽지 않습니다. 대신 배열에는 처리한 값도 남으므로, 추가 공간은 현재 대기 개수가 아니라 전체로 넣은 개수에 비례합니다.
