그리디는 지금 단계에서 기준에 맞는 선택 하나를 하고 넘어갑니다. 대표적으로 **큰 동전부터 쓰는 거스름돈**, **빨리 끝나는 회의부터 고르는 회의실 배정**이 있습니다.

다만 기준이 모든 문제에서 맞는 건 아닙니다. 이번에는 기준이 성립하는 조건을 짧게 확인하고 구현을 연습하겠습니다.

## 자주 쓰는 JS 문법

```js
console.log(Math.floor(27 / 10));
console.log(27 % 10);
console.log([1, 10, 5].sort((a, b) => b - a));
```

결과는 `2`, `7`, `[10, 5, 1]`입니다. 정수 몫은 `Math.floor()`, 나머지는 `%`, 숫자 내림차순은 `(a, b) => b - a`입니다. 여기서는 금액이 0 이상이라 내림한 값이 필요한 몫입니다.

## 대표 예제 1: 거스름돈

동전 단위는 `[1, 5, 10, 50]`이며 개수 제한이 없습니다. 67을 최소 개수로 거슬러 줍니다. 이 예제는 작은 단위가 다음 큰 단위를 나누어떨어지게 하는 동전 체계입니다.

```js
function changeCoinCount(amount) {
  const coins = [50, 10, 5, 1];
  let remaining = amount;
  let count = 0;

  for (const coin of coins) {
    const used = Math.floor(remaining / coin);
    count += used;
    remaining %= coin;
  }
  return count;
}

console.log(changeCoinCount(67));
```

답은 5입니다. 금액은 0 이상인 정수입니다.

| 동전 | 쓰는 개수 | 남은 금액 | 누적 개수 |
| --- | --- | --- | --- |
| 50 | 1 | 17 | 1 |
| 10 | 1 | 7 | 2 |
| 5 | 1 | 2 | 3 |
| 1 | 2 | 0 | 5 |

이 체계에서는 작은 동전을 여러 개 쓴 묶음을 큰 동전 하나로 교체할 수 있어 큰 단위를 먼저 쓰면 개수를 줄일 수 있습니다. 동전 종류가 m개라면 시간 O(m), 추가 공간 O(1)입니다. 위 코드는 단위가 네 개로 고정돼 있습니다.

**임의의 동전 단위에는 이 풀이가 항상 맞지 않습니다.** `[1, 3, 4]`로 6을 만들 때 큰 것부터 쓰면 `4+1+1`인 3개지만, `3+3`인 2개가 더 좋습니다.

## 대표 예제 2: 회의를 가장 많이 선택하기

회의는 `[시작, 종료]`이고 시작은 종료보다 작습니다. 한 회의가 끝나는 시각에 바로 다음 회의를 시작해도 됩니다.

```js
function maxMeetingCount(meetings) {
  const sorted = [...meetings].sort((a, b) => a[1] - b[1]);
  let lastEnd = -Infinity;
  let count = 0;

  for (const [start, end] of sorted) {
    if (start < lastEnd) continue;
    count++;
    lastEnd = end;
  }
  return count;
}

console.log(maxMeetingCount([[1, 4], [2, 3], [3, 5], [5, 6]]));
```

답은 3입니다. 종료 시각으로 정렬하면 `[2,3]`, `[1,4]`, `[3,5]`, `[5,6]`입니다.

```text
[2,3] 선택 → lastEnd = 3
[1,4] 제외 → 1은 lastEnd보다 작음
[3,5] 선택 → lastEnd = 5
[5,6] 선택 → lastEnd = 6
```

가장 빨리 끝나는 회의를 고르면 뒤에 회의를 넣을 시간을 남깁니다. 어떤 최적 일정의 첫 회의를 더 빨리 끝나는 회의로 바꿔도 뒤의 회의를 유지할 수 있다는 것이 근거입니다.

정렬을 O(n log n)으로 가정하면 전체 시간 O(n log n), 입력 복사 공간 O(n)입니다. 회의마다 보상이 달라 “개수” 대신 “보상 합”을 최대화한다면 이 기준을 그대로 쓰면 안 됩니다.

## 이번 편에서 기억할 문법

| 문법 | 쓰임 |
| --- | --- |
| `Math.floor(amount / coin)` | 사용할 동전 개수 |
| `remaining %= coin` | 사용한 뒤 남은 금액 |
| `.sort((a, b) => a[1] - b[1])` | 쌍의 두 번째 값으로 정렬 |
| `for (const [start, end] of sorted)` | 쌍을 이름 붙여 꺼내기 |
