값을 추가하면서 **그중 가장 작은 값부터 반복해서 꺼내야 할 때** 최소 힙을 사용합니다. 큐는 들어온 순서대로 꺼내지만 우선순위 큐는 정한 우선순위대로 꺼냅니다. 최소 힙에서는 작은 숫자가 우선입니다.

일반적인 JS 표준 내장 컬렉션에는 우선순위 큐가 없어 직접 구현하거나 문제 풀이 환경에서 제공하는 라이브러리를 씁니다. 여기서는 숫자만 저장하는 최소 힙으로 범위를 좁히겠습니다.

## 배열에서 부모와 자식 찾기

힙은 배열로 저장합니다. 위치가 i일 때 부모와 자식 위치는 다음과 같습니다.

```text
부모:        Math.floor((i - 1) / 2)
왼쪽 자식:   i * 2 + 1
오른쪽 자식: i * 2 + 2
```

예를 들어 `[1, 3, 2, 7, 5]`는 최소 힙입니다.

```text
        1
      /   \
     3     2
    / \
   7   5
```

부모가 자식보다 작거나 같으면 됩니다. 배열 전체가 정렬된 것은 아니지만, 첫 원소는 항상 최솟값입니다.

## 기본 구현

삽입할 때는 맨 끝에 넣고 부모보다 작으면 위로 올립니다. 꺼낼 때는 마지막 값을 맨 앞에 놓고, 작은 자식보다 크면 아래로 내립니다.

```js
class MinHeap {
  constructor() {
    this.data = [];
  }
  get size() {
    return this.data.length;
  }
  peek() {
    return this.data[0];
  }
  push(value) {
    const data = this.data;
    data.push(value);
    let i = data.length - 1;

    while (i > 0) {
      const parent = Math.floor((i - 1) / 2);
      if (data[parent] <= data[i]) break;
      [data[parent], data[i]] = [data[i], data[parent]];
      i = parent;
    }
  }
  pop() {
    const data = this.data;
    if (data.length === 0) return undefined;
    const result = data[0];
    const last = data.pop();
    if (data.length === 0) return result;

    data[0] = last;
    let i = 0;
    while (i * 2 + 1 < data.length) {
      let child = i * 2 + 1;
      if (child + 1 < data.length && data[child + 1] < data[child]) child++;
      if (data[i] <= data[child]) break;
      [data[i], data[child]] = [data[child], data[i]];
      i = child;
    }
    return result;
  }
}

const heap = new MinHeap();
for (const value of [5, 2, 3, 1]) heap.push(value);
console.log(heap.peek());
console.log(heap.pop(), heap.pop(), heap.pop(), heap.pop());
```

peek는 1이고, pop 순서는 `1, 2, 3, 5`입니다. 위 구현에서 자주 보이는 문법만 따로 보겠습니다.

| 문법 | 역할 |
| --- | --- |
| `get size()` | `heap.size`로 원소 수 읽기 |
| `[a, b] = [b, a]` | 두 값 교환 |
| `Math.floor((i - 1) / 2)` | 부모 위치 계산 |
| `break` | 힙 조건을 만족하면 이동 종료 |

부모에서 자식으로 내려갈 때는 둘 중 **더 작은 자식**과 비교합니다. 오른쪽 자식이 없는 경우도 확인해야 합니다. 원소 하나를 꺼내 비었다면 마지막 값을 다시 넣지 않고 바로 반환합니다.

push와 pop은 일반적인 배열 연산 비용을 가정하면 O(log n), peek는 O(1), 저장 공간은 O(n)입니다. 이 코드로 n개를 하나씩 넣는 초기화는 O(n log n)입니다.

## 대표 예제: 가장 작은 두 값을 섞기

점수가 0 이상인 값들이 있습니다. 아래 규칙대로 섞어 모든 값이 target 이상이 되게 합니다. 더 섞을 수 없으면 -1입니다.

```text
새 값 = 가장 작은 값 + 두 번째로 작은 값 * 2
```

```js
function mixUntil(values, target) {
  const heap = new MinHeap();
  for (const value of values) heap.push(value);
  let count = 0;

  while (heap.size > 0 && heap.peek() < target) {
    if (heap.size < 2) return -1;
    const first = heap.pop();
    const second = heap.pop();
    heap.push(first + second * 2);
    count++;
  }
  return count;
}

console.log(mixUntil([1, 2, 3, 9, 10, 12], 7));
```

앞의 MinHeap과 함께 실행합니다. 답은 2입니다.

```text
1, 2를 꺼냄 → 1 + 2*2 = 5 추가
남은 값: 3, 5, 9, 10, 12

3, 5를 꺼냄 → 3 + 5*2 = 13 추가
남은 값: 9, 10, 12, 13 → 최솟값 9도 7 이상이므로 종료
```

이 목록은 이해를 위해 정렬해서 적은 것이며, 실제 힙 배열 전체가 이 순서로 놓인다는 뜻은 아닙니다. 한 번 섞을 때 원소가 하나 줄어 최대 n - 1회 진행합니다. 초기 삽입까지 시간 O(n log n), 공간 O(n)입니다. 입력이 비어 있으면 위 함수는 처리할 값이 없으므로 0을 반환하는 규칙입니다.

작은 입력은 매번 정렬해 풀어도 되지만, 값을 넣고 작은 값을 꺼내는 작업이 반복되면 힙을 검토합니다. 우선 `push`, `pop`, `peek`, `size` 사용법과 두 값 교환부터 익히겠습니다. 다음은 [그래프](/posts/algorithm-10-graph)입니다.
