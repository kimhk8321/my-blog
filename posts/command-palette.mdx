VS Code, Linear, Notion, GitHub… 요즘 잘 만든 앱은 대부분 **⌘K 커맨드 팔레트**를 가지고 있습니다. 아무 화면에서나 단축키 하나로 명령·검색·이동을 해결하는 이 패턴은, 파워 유저에게는 마우스보다 빠른 길이죠.

만드는 데 필요한 건 세 가지입니다 — **퍼지 검색**, **키보드 내비게이션**, 그리고 **오버레이 UX**. 하나씩 짜 봅니다.

## 퍼지 검색 — 부분 순서 매칭

퍼지 검색의 가장 단순하고 효과적인 형태는 **부분 순서 매칭(subsequence match)** 입니다. "쿼리의 글자들이 순서대로(연속일 필요 없이) 텍스트에 나타나는가?"를 봅니다.

```js
function fuzzyMatch(query, text) {
  const q = query.toLowerCase();
  const t = text.toLowerCase();
  let qi = 0;
  for (const ch of t) {
    if (ch === q[qi]) qi++;      // 글자가 순서대로 걸리면 다음으로
    if (qi === q.length) return true;
  }
  return qi === q.length;
}

fuzzyMatch("cmd", "command palette"); // true (c...m...d)
fuzzyMatch("dm", "다크 모드");         // (초성/문자 매칭에 따라)
```

`command`에서 `cmd`를 치면 `c`, `m`, `d`가 순서대로 발견돼 매칭됩니다. 이 단순한 규칙만으로도 "생각나는 글자 몇 개"로 명령을 찾는 경험이 만들어집니다.

실전에서는 여기에 **점수(score)** 를 매깁니다 — 연속으로 매칭될수록, 단어 첫 글자에 매칭될수록 높은 점수를 줘서 정렬하죠. `fzf`, `fuse.js`가 이 점수 로직을 정교하게 다듬은 라이브러리입니다.

## 키보드 내비게이션 — active 인덱스

목록을 키보드로 다루는 핵심은 **"지금 몇 번째가 활성인가"(active index)** 하나입니다. 화살표로 이 인덱스를 옮기고, Enter로 그 항목을 선택합니다.

```jsx
const [active, setActive] = useState(0);

const onKeyDown = (e) => {
  if (e.key === "ArrowDown") {
    e.preventDefault(); // 페이지 스크롤 방지
    setActive((a) => Math.min(a + 1, filtered.length - 1));
  } else if (e.key === "ArrowUp") {
    e.preventDefault();
    setActive((a) => Math.max(a - 1, 0));
  } else if (e.key === "Enter") {
    choose(filtered[active]);
  } else if (e.key === "Escape") {
    close();
  }
};
```

주의할 디테일: 검색어가 바뀌어 목록이 줄어들면 `active`가 범위를 벗어날 수 있습니다. 쿼리가 바뀔 때 `active`를 0으로 리셋하면 안전합니다.

```jsx
useEffect(() => setActive(0), [query]);
```

`ArrowDown`/`ArrowUp`에서 `preventDefault()`를 부르는 것도 중요합니다 — 안 그러면 화살표가 팔레트 이동과 **페이지 스크롤을 동시에** 일으킵니다.

## 열고 닫기 — 포커스 관리

팔레트가 뜨면 **입력창에 자동 포커스**가 가야 바로 타이핑할 수 있습니다.

```jsx
useEffect(() => {
  if (open) inputRef.current?.focus();
}, [open]);
```

그리고 이건 사실상 [접근 가능한 모달](/posts/accessible-modal)입니다 — 배경 클릭으로 닫기, Esc로 닫기, 포커스 트랩, 닫을 때 원래 위치로 포커스 복귀까지 챙기면 완성도가 올라갑니다. 커맨드 팔레트는 "모달 + 검색 + 키보드 목록"의 합성이라고 봐도 됩니다.

## 전역 단축키 — ⌘K 바인딩

어느 화면에서나 열리려면 전역 키 리스너가 필요합니다. `metaKey`(맥)와 `ctrlKey`(윈도우)를 함께 봅니다.

```jsx
useEffect(() => {
  const onKey = (e) => {
    if ((e.metaKey || e.ctrlKey) && e.key === "k") {
      e.preventDefault(); // 브라우저 기본 동작 차단
      setOpen((o) => !o);
    }
  };
  window.addEventListener("keydown", onKey);
  return () => window.removeEventListener("keydown", onKey);
}, []);
```

`preventDefault`가 없으면 브라우저의 기본 ⌘K(주소창 검색 등)와 충돌합니다.

## 접근성 한 가지

목록을 스크린 리더가 이해하려면 `role="listbox"`/`role="option"`과 `aria-activedescendant`로 "지금 몇 번째가 활성인지"를 알려야 합니다. 마우스 사용자에겐 안 보이지만, 키보드·스크린 리더 사용자에겐 이게 팔레트를 쓸 수 있느냐를 가릅니다.
