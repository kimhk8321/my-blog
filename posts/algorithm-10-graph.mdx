그래프는 대상과 대상 사이의 연결을 나타냅니다. 사람 사이의 친구 관계나 도시 사이의 길도 그래프로 볼 수 있습니다. 이번에는 **연결 목록을 JS 배열로 만드는 방법**과 그 목록을 따라가는 기본 탐색을 정리합니다.

## 자주 쓰는 JS 문법: 인접 리스트

정점은 0부터 n - 1까지 번호를 붙이고, 간선 `[a, b]`는 a와 b가 연결돼 있다는 뜻입니다. 예제는 양쪽으로 이동할 수 있는 무방향 그래프입니다.

```js
function buildGraph(n, edges) {
  const graph = Array.from({ length: n }, () => []);

  for (const [a, b] of edges) {
    graph[a].push(b);
    graph[b].push(a);
  }
  return graph;
}

console.log(buildGraph(4, [[0, 1], [0, 2], [2, 3]]));
```

결과는 `[[1,2], [0], [0,3], [2]]`입니다.

```text
0번의 이웃: 1, 2
1번의 이웃: 0
2번의 이웃: 0, 3
3번의 이웃: 2
```

`graph[node]`를 순회하면 그 정점에서 갈 수 있는 이웃만 확인할 수 있습니다. 한쪽 방향으로만 이동하는 문제라면 `graph[a].push(b)`만 넣습니다.

## 대표 예제 1: 연결된 그룹 수

서로 연결된 컴퓨터끼리 하나의 그룹으로 봅니다. 컴퓨터 5대가 있고 연결이 `[[0,1], [1,2], [3,4]]`라면 그룹은 `{0,1,2}`, `{3,4}`의 두 개입니다.

스택으로 DFS를 하면서 한 그룹을 전부 방문합니다. 아직 방문하지 않은 정점에서 탐색을 새로 시작할 때마다 그룹 수를 올립니다.

```js
function countNetworks(n, edges) {
  const graph = buildGraph(n, edges);
  const visited = Array(n).fill(false);
  let count = 0;

  for (let start = 0; start < n; start++) {
    if (visited[start]) continue;
    count++;
    const stack = [start];
    visited[start] = true;

    while (stack.length > 0) {
      const node = stack.pop();
      for (const next of graph[node]) {
        if (visited[next]) continue;
        visited[next] = true;
        stack.push(next);
      }
    }
  }
  return count;
}

console.log(countNetworks(5, [[0, 1], [1, 2], [3, 4]]));
```

앞의 `buildGraph()`와 함께 실행합니다.

답은 2입니다. 0에서 시작해 0·1·2를 방문하고, 다음 새 시작점인 3에서 3·4를 방문합니다. 연결이 없는 컴퓨터도 혼자 하나의 그룹이므로 `countNetworks(3, [])`는 3입니다.

여기서는 한 번 확인한 정점을 전역 visited에 남깁니다. [순열 DFS](/posts/algorithm-05-dfs-bfs)는 다음 순열에서도 원소를 사용해야 해서 방문을 해제했지만, 그룹 찾기는 같은 정점을 다시 셀 필요가 없습니다.

## 대표 예제 2: 두 정점 사이 최소 이동 횟수

모든 연결의 이동 비용이 1이라면 BFS를 씁니다. 아래 코드도 위의 `buildGraph()`와 함께 실행합니다. 시작과 도착은 유효한 정점 번호입니다.

```js
function graphDistance(n, edges, start, end) {
  const graph = buildGraph(n, edges);
  const distance = Array(n).fill(-1);
  const queue = [start];
  let head = 0;
  distance[start] = 0;

  while (head < queue.length) {
    const node = queue[head++];
    if (node === end) return distance[node];

    for (const next of graph[node]) {
      if (distance[next] !== -1) continue;
      distance[next] = distance[node] + 1;
      queue.push(next);
    }
  }
  return -1;
}

console.log(graphDistance(4, [[0, 1], [0, 2], [2, 3]], 0, 3));
```

답은 2입니다. `0 → 2 → 3`으로 이동합니다. 미로 BFS와 구조는 같고, 네 방향 좌표 대신 `graph[node]`에서 다음 정점을 읽는 점만 다릅니다.

정점 수 V, 간선 수 E일 때 인접 리스트 생성과 두 탐색의 시간은 각각 O(V + E)입니다. 그래프 저장까지 포함한 공간도 O(V + E)입니다.

## 다시 쓸 기본 패턴

| 필요한 작업 | JS 구현 |
| --- | --- |
| 이웃 목록 만들기 | `Array.from({ length: n }, () => [])` |
| 연결 추가 | `graph[a].push(b)` |
| 이웃 순회 | `for (const next of graph[node])` |
| 깊이 우선으로 처리 | 스택의 `push/pop` |
| 가까운 순서대로 처리 | 큐의 `push/head` |
| 같은 정점 중복 처리 막기 | visited 또는 distance |

가중치가 다른 최단 경로, 작업의 선행 순서, 간선을 추가하며 집합을 합치는 문제는 각각 다익스트라·위상 정렬·Union-Find로 이어집니다. 우선 이번 편의 연결 목록과 방문 처리부터 익힌 뒤 확장하면 됩니다.
