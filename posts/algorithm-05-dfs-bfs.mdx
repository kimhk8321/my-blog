BFS는 가까운 곳부터 차례대로, DFS는 한 선택을 끝까지 따라간 뒤 돌아오는 탐색입니다. 이번에는 **BFS로 최소 이동 횟수**, **DFS로 순열**을 구해 보겠습니다.

## 먼저 익힐 JS 문법

방문 여부나 거리를 저장할 때는 배열을 만듭니다.

```js
const visited = Array(3).fill(false);
const distance = Array.from({ length: 2 }, () => Array(3).fill(-1));
const position = [1, 2];
const [row, col] = position;
console.log(visited, distance, row, col);
```

`Array(3).fill(false)`는 `[false, false, false]`입니다. `Array.from()`의 함수를 호출할 때마다 새 행을 만들어, 이차원 배열의 행이 서로 다른 배열이 되게 합니다. `Array(2).fill(Array(3).fill(-1))`처럼 만들면 두 행이 같은 배열을 참조하므로 한 행을 고칠 때 다른 행도 바뀝니다. [MDN Array.from](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Array/from)을 참고했습니다.

`const [row, col] = position`은 좌표 배열의 두 값을 꺼내 이름을 붙이는 구조 분해 할당입니다.

## BFS 대표 예제: 미로에서 최소 이동 횟수

0은 통로, 1은 벽입니다. 왼쪽 위에서 오른쪽 아래로 가고 상하좌우로 한 칸씩 움직입니다. 시작 위치의 이동 횟수는 0이며 도착할 수 없으면 -1을 반환합니다. 입력은 직사각형 격자입니다.

```js
function shortestGridPath(grid) {
  const rows = grid.length;
  const cols = grid[0]?.length ?? 0;
  if (rows === 0 || cols === 0) return -1;
  if (grid[0][0] === 1 || grid[rows - 1][cols - 1] === 1) return -1;

  const distance = Array.from({ length: rows }, () => Array(cols).fill(-1));
  const queue = [[0, 0]];
  let head = 0;
  distance[0][0] = 0;
  const moves = [[1, 0], [-1, 0], [0, 1], [0, -1]];

  while (head < queue.length) {
    const [row, col] = queue[head++];
    if (row === rows - 1 && col === cols - 1) return distance[row][col];

    for (const [dr, dc] of moves) {
      const nextRow = row + dr;
      const nextCol = col + dc;
      if (nextRow < 0 || nextRow >= rows || nextCol < 0 || nextCol >= cols) continue;
      if (grid[nextRow][nextCol] === 1) continue;
      if (distance[nextRow][nextCol] !== -1) continue;

      distance[nextRow][nextCol] = distance[row][col] + 1;
      queue.push([nextRow, nextCol]);
    }
  }
  return -1;
}

console.log(shortestGridPath([
  [0, 0, 0],
  [1, 1, 0],
  [0, 0, 0],
]));
```

답은 4입니다. `(0,0) → (0,1) → (0,2) → (1,2) → (2,2)`로 움직입니다.

코드를 세 덩어리로 읽으면 됩니다.

1. 큐에서 좌표 하나를 꺼낸다.
2. 네 방향 중 범위 안이고 벽이 아니며 방문하지 않은 칸을 찾는다.
3. 그 칸의 거리를 현재 거리 + 1로 저장하고 큐에 넣는다.

`distance`의 -1은 아직 방문하지 않았다는 표시입니다. 별도의 방문 배열 없이 거리와 방문 여부를 같이 저장합니다. **큐에 넣을 때** 거리를 기록해야 다른 칸에서 같은 좌표를 또 넣지 않습니다.

```text
거리 0: (0,0)
거리 1: (0,1)
거리 2: (0,2)
거리 3: (1,2)
거리 4: (2,2)
```

데모는 조금 더 큰 격자입니다. 파란 칸은 큐에서 대기하고, 초록 칸은 이번에 꺼낸 칸입니다. 숫자가 작은 칸부터 처리되는지 확인해 보세요.

각 이동의 비용이 같아 가까운 칸부터 방문하는 BFS로 최단 거리를 구할 수 있습니다. 이동 비용이 다르면 이 풀이를 그대로 사용하면 안 됩니다. 시간과 추가 공간은 모두 O(행 × 열)입니다.

## DFS 대표 예제: 두 개를 뽑아 순열 만들기

`[1, 2, 3]`에서 서로 다른 두 원소를 뽑아 나열합니다. `[1, 2]`와 `[2, 1]`은 다른 답입니다. 입력 원소는 서로 다르다고 가정합니다.

```js
function permutations(nums, r) {
  const result = [];
  const path = [];
  const used = Array(nums.length).fill(false);

  function dfs() {
    if (path.length === r) {
      result.push([...path]);
      return;
    }

    for (let i = 0; i < nums.length; i++) {
      if (used[i]) continue;
      used[i] = true;
      path.push(nums[i]);
      dfs();
      path.pop();
      used[i] = false;
    }
  }

  dfs();
  return result;
}

console.log(permutations([1, 2, 3], 2));
```

답은 `[[1,2], [1,3], [2,1], [2,3], [3,1], [3,2]]`입니다. r은 0 이상인 정수이며, 0개를 고르면 `[[]]`, 원소 수보다 많이 고르면 `[]`입니다.

처음에 1을 고르는 흐름을 따라가면 다음과 같습니다.

```text
[] → [1] → [1,2] 저장
         → [1]로 복귀
         → [1,3] 저장
         → [1]로 복귀
   → []로 복귀 → 다음으로 2 선택
```

`used[i]`는 **현재 path에서** 해당 원소를 골랐는지 나타냅니다. 돌아올 때 false로 바꿔야 다른 순열에서도 그 원소를 사용할 수 있습니다. `path.pop()`도 같은 이유로 필요합니다.

답은 `[...path]`로 복사해서 넣습니다. path 자체를 넣으면 나중에 pop할 때 이미 저장한 답까지 바뀝니다. 모든 원소를 뽑는 최악의 경우 답이 n!개라 전체 시간은 결과 복사를 포함해 O(n × n!) 수준입니다. DFS는 입력이 작을 때 쓰고, 결과 저장 외의 방문 배열·경로·호출 스택은 O(n)입니다.
