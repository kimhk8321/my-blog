투 포인터는 배열의 두 위치를 따로 움직이는 방법입니다. 이번에는 **양끝에서 두 수를 찾는 예제**와 **같은 길이의 구간을 옮기는 예제** 두 가지만 연습합니다.

## 자주 쓰는 JS 문법

```js
const numbers = [5, 1, 3, 2, 4];
const sorted = [...numbers].sort((a, b) => a - b);
console.log(sorted);

let left = 0;
let right = sorted.length - 1;
left++;
right--;
console.log(left, right);
```

숫자 오름차순 정렬은 `(a, b) => a - b`입니다. 기본 `sort()`는 숫자 크기가 아니라 문자열 기준으로 비교하므로 비교 함수를 넣습니다. `[...numbers]`는 원본을 바꾸지 않으려고 복사한 것입니다. [MDN sort](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Array/sort)에서 확인할 수 있습니다.

## 대표 예제 1: 합이 target인 두 수

**오름차순으로 정렬된 배열**에서 합이 target인 두 원소의 인덱스 한 쌍을 찾습니다. 같은 위치를 두 번 사용할 수 없고, 없으면 `null`입니다.

```js
function twoSumSorted(nums, target) {
  let left = 0;
  let right = nums.length - 1;

  while (left < right) {
    const sum = nums[left] + nums[right];
    if (sum === target) return [left, right];
    if (sum < target) left++;
    else right--;
  }
  return null;
}

console.log(twoSumSorted([1, 2, 3, 4, 5], 6));
```

처음부터 `1 + 5 = 6`이므로 답은 `[0, 4]`입니다. target을 7로 바꾸면 한 단계 더 움직입니다.

| left 값 | right 값 | 합 | 다음 동작 |
| --- | --- | --- | --- |
| 1 | 5 | 6 | 작으므로 left를 오른쪽으로 |
| 2 | 5 | 7 | 정답 반환 |

합이 작으면 더 큰 값을 써야 하니 left를 늘리고, 크면 더 작은 값을 써야 하니 right를 줄입니다. 이 판단은 정렬된 배열이기 때문에 가능합니다.

두 위치가 만나면 같은 원소를 두 번 쓰게 되므로 `left < right` 동안만 반복합니다. 이미 정렬된 입력에서는 시간 O(n), 추가 공간 O(1)입니다. 처음에 정렬했다면 그 비용도 포함해야 하고, 반환되는 인덱스는 정렬된 배열 기준이라는 점을 주의합니다.

## 대표 예제 2: 연속된 세 수의 최대합

길이가 k인 연속 구간의 최대합을 구합니다. 예를 들어 `[2, 1, 5, 1, 3, 2]`에서 세 원소씩 묶습니다.

```text
[2, 1, 5]          → 8
   [1, 5, 1]       → 7
      [5, 1, 3]    → 9
         [1, 3, 2] → 6
```

다음 구간의 합을 처음부터 계산하지 않아도 됩니다. 앞에서 빠지는 값은 빼고 뒤에서 들어오는 값은 더합니다.

```js
function maxWindowSum(nums, k) {
  if (!Number.isInteger(k) || k < 1 || k > nums.length) return null;

  let sum = 0;
  for (let i = 0; i < k; i++) sum += nums[i];
  let best = sum;

  for (let right = k; right < nums.length; right++) {
    sum -= nums[right - k];
    sum += nums[right];
    best = Math.max(best, sum);
  }
  return best;
}

console.log(maxWindowSum([2, 1, 5, 1, 3, 2], 3));
```

답은 9입니다. 첫 구간에서 두 번째로 움직일 때는 `8 - 2 + 1 = 7`입니다. `Math.max(best, sum)`은 지금까지의 최대값과 새 구간의 합 중 더 큰 것을 남깁니다.

구간 길이를 고정한 채 옆으로 미는 방식이 슬라이딩 윈도우입니다. 시간 O(n), 추가 공간 O(1)이며 이 고정 길이 풀이에는 음수가 섞여도 됩니다. 최대값을 0이 아니라 첫 구간합으로 시작해야 모두 음수인 입력도 처리할 수 있습니다.

## 이번 편에서 기억할 문법

| 문법 | 쓰임 |
| --- | --- |
| `left++`, `right--` | 포인터를 한 칸 이동 |
| `nums.length - 1` | 마지막 인덱스 |
| `sum -= 빠지는값` | 이전 구간 원소 제거 |
| `sum += 들어오는값` | 새 구간 원소 추가 |
| `Math.max(a, b)` | 더 큰 값 선택 |

다시 풀 때는 target을 바꿔 포인터가 어느 쪽으로 움직이는지, k를 1과 배열 길이로 바꿔 구간합이 맞는지 확인해 보겠습니다. 다음은 [이분 탐색](/posts/algorithm-04-binary-search)입니다.
