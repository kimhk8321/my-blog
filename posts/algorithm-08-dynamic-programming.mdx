DP는 **이미 구한 작은 문제의 답을 저장해 다음 답을 만드는 방법**입니다. 처음에는 상태가 여러 개인 문제보다, 인덱스 하나로 뜻을 설명할 수 있는 배열 DP부터 복습하겠습니다.

## 자주 쓰는 JS 문법

```js
const dp = Array(6).fill(0);
dp[0] = 1;
dp[1] = 1;
console.log(dp);
console.log(Math.max(3, 5));
```

`Array(6).fill(0)`은 0이 여섯 개 있는 배열입니다. 인덱스는 0부터 시작하므로 5번 계단까지 저장하려면 길이를 6으로 만듭니다. 최대값을 고를 때는 `Math.max()`를 사용합니다.

## 대표 예제 1: 계단 오르는 방법 수

한 번에 1칸 또는 2칸 올라 n번째 계단에 도착하는 방법 수를 구합니다. n은 0 이상인 정수이고, 0칸은 아무 이동도 하지 않는 한 가지 방법으로 셉니다.

`dp[i]`는 **i번째 계단까지 올라오는 방법 수**입니다. i에 도착하는 마지막 이동은 둘 중 하나입니다.

- i - 1까지 왔다가 1칸 올라오기
- i - 2까지 왔다가 2칸 올라오기

두 경우를 더하면 됩니다.

```js
function climbWays(n) {
  if (n <= 1) return 1;
  const dp = Array(n + 1).fill(0);
  dp[0] = 1;
  dp[1] = 1;

  for (let i = 2; i <= n; i++) {
    dp[i] = dp[i - 1] + dp[i - 2];
  }
  return dp[n];
}

console.log(climbWays(3));
console.log(climbWays(5));
```

답은 3과 8입니다. 3칸의 방법은 `[1,1,1]`, `[1,2]`, `[2,1]`입니다.

| i | 계산 | dp[i] |
| --- | --- | --- |
| 0 | 초기값 | 1 |
| 1 | 초기값 | 1 |
| 2 | 1 + 1 | 2 |
| 3 | 2 + 1 | 3 |
| 4 | 3 + 2 | 5 |
| 5 | 5 + 3 | 8 |

매번 이전 두 값을 재사용하므로 시간 O(n), 배열 공간 O(n)입니다. n이 아주 커서 방법 수가 안전한 정수 범위를 넘으면 `BigInt`나 문제에서 지정한 나머지 계산이 필요합니다.

## 대표 예제 2: 붙어 있는 값은 함께 선택하지 않기

`[2, 7, 9, 3, 1]`에서 인접한 두 위치를 함께 고르지 않고 합을 최대화합니다. 값은 0 이상이며 아무것도 고르지 않아도 됩니다.

`dp[i]`는 **앞의 i개 원소까지 확인했을 때 가능한 최대합**입니다. 현재 원소를 고르지 않으면 이전 최대합을 쓰고, 고르면 바로 앞 원소를 건너뛰어야 합니다.

```js
function maxNonAdjacentSum(nums) {
  if (nums.length === 0) return 0;
  const dp = Array(nums.length + 1).fill(0);
  dp[1] = nums[0];

  for (let i = 2; i <= nums.length; i++) {
    const skip = dp[i - 1];
    const take = dp[i - 2] + nums[i - 1];
    dp[i] = Math.max(skip, take);
  }
  return dp[nums.length];
}

console.log(maxNonAdjacentSum([2, 7, 9, 3, 1]));
```

답은 `2 + 9 + 1 = 12`입니다.

| 지금 본 값 | 고르지 않음 skip | 고름 take | 최대합 |
| --- | --- | --- | --- |
| 2 | 초기값 | 초기값 | 2 |
| 7 | 2 | 0 + 7 | 7 |
| 9 | 7 | 2 + 9 | 11 |
| 3 | 11 | 7 + 3 | 11 |
| 1 | 11 | 11 + 1 | 12 |

`dp`는 “앞의 몇 개”를 기준으로 하고 `nums`는 0번부터 시작하므로, 현재 원소가 `nums[i - 1]`입니다. 이 인덱스 차이를 손으로 확인하면 코드가 훨씬 덜 헷갈립니다. 시간과 추가 공간은 O(n)입니다.

## DP 코드를 쓰기 전 한 문장

`dp[i]`가 **방법 수인지, 최소 개수인지, 최대 합인지** 먼저 적습니다. 방법 수는 경우를 더하고, 최대값 문제는 선택들을 `Math.max()`로 비교합니다. 초기값도 그 뜻에 맞춰야 합니다.

계단 수를 0·1·2로, 원소 배열을 빈 배열·한 원소로 바꿔 경계를 확인해 보겠습니다. 처음에는 배열 전체를 저장하고, 익숙해진 뒤 이전 두 값만 남기는 공간 압축을 연습해도 됩니다. 다음은 [힙·우선순위 큐](/posts/algorithm-09-heap)입니다.
